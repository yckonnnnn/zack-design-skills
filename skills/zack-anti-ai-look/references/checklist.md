# AI 味完整清单 · 60 条

使用方法：从上往下过，命中的记下来并标注严重度，**不要边看边改**。全部过完再按 `zack-anti-ai-look` 的修复顺序动手。

严重度：`P0` 直接劝退 ｜ `P1` 明显廉价 ｜ `P2` 可以更好

---

## A. 排版（A1–A10）

- **A1 · P0** 字体是 Inter / Roboto / Arial / Open Sans / 默认 `sans-serif`。
- **A2 · P0** 桌面端（1440px）标题超过 2 行，且原因是正文列过窄。
- **A3 · P0** 字号阶梯是等差（16/18/20/22/24），没有任何比例关系。
- **A4 · P1** 字号种类超过 6 个，或小于 3 个（没有层级）。
- **A5 · P1** 展示级字号缺失：全页最大字号 < 36px，页面没有视觉重力中心。
- **A6 · P1** 大字号没有负字距；小字号没有正字距（`0.01em`–`0.03em`）用于全大写。
- **A7 · P1** 标题行高 1.4–1.6（过松），正文行高 < 1.4（过紧）。
- **A8 · P1** 正文行长超出 75–80 字符，或短于 40 字符。
- **A9 · P1** 数字未启用 `tabular-nums`，价格表、指标卡、表格列对不齐。
- **A10 · P2** 中英混排未处理：中文用 700 冒充粗体、中西文间无空隙、标点用半角。

## B. 颜色与表面（B1–B9）

- **B1 · P0** 紫→蓝 或 紫→粉 的大面积渐变背景。
- **B2 · P0** 渐变文字标题（`background-clip: text`）。
- **B3 · P0** 同时有 3 个以上颜色在承担「强调」职责。
- **B4 · P1** 只有白 + 单一灰，没有 4 级以上的中性色阶。
- **B5 · P1** 直接使用框架默认调色板原值，中性色没有色相倾向（死灰）。
- **B6 · P1** 正文 < 16px 且颜色浅于 4.5:1 对比度。
- **B7 · P1** 大面积纯 `#000` / 纯 `#FFF`。
- **B8 · P1** 高饱和主色铺满整屏背景区。
- **B9 · P2** 玻璃拟态 / 霓虹辉光 / 3D 球体装饰无理由出现。

## C. 布局与节奏（C1–C11）

- **C1 · P0** 每一屏都居中，全页没有一个左对齐的锚点。
- **C2 · P0** 每一屏的上下留白完全相同，没有疏密。
- **C3 · P1** 三张等宽等高卡片是唯一的版式语言。
- **C4 · P1** bento 网格存在空洞（某格空着或内容撑不满）。
- **C5 · P1** 卡片嵌套超过两层。
- **C6 · P1** 全宽 sticky navbar 贴顶且无功能理由。
- **C7 · P1** 内容容器宽度 ≤ 1200px 且内容顶到容器边缘（无内缩）。
- **C8 · P1** 左右交替（图左文右 / 文左图右）反复出现，是同一形式的镜像。
- **C9 · P1** 首屏采用「巨型数字 + 小标签 + 渐变强调」这一默认解。
- **C10 · P1** hero 高度用 `100vh`，移动端被地址栏截断。
- **C11 · P2** 全页 8–12 个 section 但只有 2 种区块形式。

## D. 组件与状态（D1–D12）

- **D1 · P1** 按钮、卡片、标签全是 `rounded-full` 药丸。
- **D2 · P1** 使用框架默认重阴影（`shadow-md/lg/xl` 原值）。
- **D3 · P1** 到处是 1px 灰色实线边框，用边框代替层级。
- **D4 · P0** 没有 `:focus-visible` 样式，键盘不可用。
- **D5 · P1** 缺 hover 状态。
- **D6 · P1** 缺 active / pressed 反馈。
- **D7 · P1** 缺 disabled 状态。
- **D8 · P1** 缺 loading / 骨架屏。
- **D9 · P1** 缺 empty 状态。
- **D10 · P1** 缺 error 状态。
- **D11 · P1** `transition: all ...`。
- **D12 · P2** 图标是粗描边默认图标库，线宽与字号不匹配。

## E. 文案（E1–E11）

- **E1 · P0** 出现「赋能」「触手可及」「开启新时代」「引领变革」「让 X 更简单」「重新定义」。
- **E2 · P0** 首屏读完说不出「你是干嘛的、给谁、解决什么」。
- **E3 · P0** 编造客户名、数据或评价。
- **E4 · P1** 全页没有一个具体数字。
- **E5 · P1** 一次列 8 个以上卖点。
- **E6 · P1** 「已被 N+ 企业信赖」无出处。
- **E7 · P1** 五条以上结构相同的五星好评。
- **E8 · P1** 出现 `FEATURE 01` / `SECTION 02` / `STEP 03` 元标签。
- **E9 · P1** CTA 是「了解更多」「立即体验」「开始使用」等无差别动词。
- **E10 · P2** FAQ 答案是空泛的营销话术，没回答问题。
- **E11 · P2** 页脚 8 个以上死链接。

## F. 内容真实性（F1–F4）

- **F1 · P0** 价格页用「—」「联系我们」占位，没有真实价格。
- **F2 · P1** 功能点描述的是能力名词而不是用户可感知的结果。
- **F3 · P1** 社证区是 5 个灰色占位方块（假 logo 墙）。
- **F4 · P1** 有「联系我们」但没有电话/邮箱/表单，或表单无校验、无成功反馈。

## G. 动效（G1–G3）

- **G1 · P1** 状态切换是硬切，完全没有过渡。
- **G2 · P1** 反过来：所有元素都用同样的滚动淡入上移，节奏一致（等于没有动效设计）。
- **G3 · P2** 时长 < 100ms（看不见）或 > 600ms（拖沓）；缓动是 `linear` / `ease-in-out` 原值。

## 打分

| 命中 | 判定 |
|---|---|
| 任何 P0 | **未通过**。先修 P0，不要谈优化。 |
| 4 条以上 P1 | **有 AI 味**。按修复顺序做一遍。 |
| 1–3 条 P1 | 基本可用，做定点打磨。 |
| 只剩 P2 | 可以交付。 |

**P0 的数量比总分重要。** 一个 P0 就足以让访客在 3 秒内判定「这是个模板站」，其余做的再多也救不回来。
